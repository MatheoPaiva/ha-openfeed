Security, privacy and reliability fixes.

- **Privacy.** Diagnostics now redact the service point address, contacts and URL ([#19](https://github.com/purcell-lab/ha-openfeed/pull/19)). The NMI is kept out of statistic IDs, entity IDs, device names and attributes for new installs ([#25](https://github.com/purcell-lab/ha-openfeed/pull/25)). Existing installs keep their current IDs, so history, Energy dashboard sources and automations keep working. The `national_metering_id` attribute is removed from Meter status; the full NMI stays on the disabled-by-default NMI sensor.
- **Security.** Pagination and discovery links are only followed on the expected origin ([#20](https://github.com/purcell-lab/ha-openfeed/pull/20)). The refresh token is revoked when the integration is removed ([#21](https://github.com/purcell-lab/ha-openfeed/pull/21)). The redirect URL must be https unless plain http is explicitly allowed ([#22](https://github.com/purcell-lab/ha-openfeed/pull/22)).
- **Reliability.** Setup keeps its keys across attempts and returns sign-in failures to the form ([#23](https://github.com/purcell-lab/ha-openfeed/pull/23)). One meter's usage or DER error no longer makes every entity unavailable; the last good data is kept and the failed call retries next poll ([#24](https://github.com/purcell-lab/ha-openfeed/pull/24)).

Update needs a Home Assistant restart. The config entry migrates automatically to minor version 2 with legacy meter naming.
