A sidebar dashboard, payments and refunds kept apart, and Nabu Casa guidance.

![openfeed sidebar dashboard](https://raw.githubusercontent.com/purcell-lab/ha-openfeed/main/docs/images/dashboard-desktop.png)

- **Sidebar dashboard.** "Energy data" appears in the sidebar after install. It shows grid energy, hourly grid power (mean and peak), daily peaks, bills, payments, monthly charges and the DER register. It is built from your shared accounts each time it opens, so it updates with each release. Turn it off in the integration options.
- **Payments and refunds split.** The `_payments` statistic now holds only money you paid, as a positive amount. A new `_refunds` statistic holds money paid back to you. The old signed `_payments` series is cleared once and rebuilt. New sensors: Last payment and, once a refund exists, Last refund, each with date and method.
- **Grid power visible.** The hourly import and export power statistics are now charted on the dashboard. They were already recorded, but had no entity, so they did not appear in the History panel.
- **Nabu Casa.** The README explains remote access. Reconfigure can now change the Home Assistant URL used for sign-in, for example to your Nabu Casa remote URL.
- Diagnostics now include the payment method on payment lines.

Update needs a Home Assistant restart.
